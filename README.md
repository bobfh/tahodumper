# TahoCard Dumper (PC/SC Tachograph Reader)

Приложение для чтения и дампа данных с карт тахографа (водительских и карт мастерских) в стандартный бинарный формат `.DDD` (ЕСТР / Регламент ЕС 3821/85 Приложение 1B и Регламент 2016/799 Приложение 1C) через стандартные PC/SC считыватели смарт-карт (например, Feitian R502, Identiv, OMNIKEY).

---

## ⚡ Быстрая загрузка и запуск в текущую папку через PowerShell (`iex`)

Откройте PowerShell в любой папке, куда хотите скачать программу, и выполните одну команду:

```powershell
irm https://raw.githubusercontent.com/bobfh/tahodumper/main/get.ps1 | iex
```
*или классический синтаксис:*
```powershell
iex (irm https://raw.githubusercontent.com/bobfh/tahodumper/main/get.ps1)
```

Скрипт автоматически скачает `TahoDumper.exe` в вашу текущую папку и сразу запустит его.

### Прямая загрузка исполняемого файла в папку (без скрипта):
```powershell
iwr -Uri "https://raw.githubusercontent.com/bobfh/tahodumper/main/release/TahoDumper.exe" -OutFile ".\TahoDumper.exe"; .\TahoDumper.exe
```

## Возможности

* 🔍 **Автоматическое обнаружение считывателей:** Сканирует подсистему Windows PC/SC и выводит список доступных устройств. Если ридер не подключен, выводит понятное уведомление «Ридеры не найдены».
* 🔄 **Выбор устройства и горячее обновление:** Возможность выбрать нужный ридер из выпадающего списка и обновить список кнопкой «Обновить».
* 🔐 **Поддержка карт мастерской:** Возможность ввода PIN-кода для аутентификации (команда `VERIFY CHV`). Для обычных карт водителя PIN не требуется.
* 📦 **Полный дамп структуры Elementary Files (EF):** 
  * Чтение корневых файлов `EF_ICC` (0x0002) и `EF_IC` (0x0005) из Master File (`MF 3F00`).
  * Чтение файлов приложения тахографа (`DF TACHO`): идентификация водителя/мастерской (`EF_Identification` 0x0520), идентификация приложения (`EF_Application_Identification` 0x0501), события (`EF_Events_Data` 0x0502), ошибки (`EF_Faults_Data` 0x0503), журнал активности (`EF_Driver_Activity_Data` 0x0504), использованные ТС (`EF_Vehicles_Used` 0x0505), места начала/конца смены (`EF_Places` 0x0506), текущее использование (`EF_Current_Usage` 0x0507), активность контроля (`EF_Control_Activity_Data` 0x0508), специальные условия (`EF_Specific_Conditions` 0x0522), сертификаты (`EF_Card_Certificate` 0xC100, `EF_CA_Certificate` 0xC108), калибровки (`EF_Calibration` 0x0509, `EF_Calibration_Data` 0x050A) и защищенные данные сенсора (`EF_Sensor_Installation_Data` 0x050B).
* 🎯 **Адаптивное чтение коротких секций:** Автоматическое определение точной длины файлов (при статусе `SW=6700`), что исключает пропуск мелких секций (10, 19, 46, 56 байт).
* 💾 **Сохранение в формат `.DDD`:** Автоматическое извлечение фамилии/названия владельца и номера карты для формирования имени файла по стандарту (например, `C_ANTA_00000000005AEF05_20260924_133006.ddd`) в папку `dumps/` рядом с программой.
* 📜 **Полный детальный Debug-логер:** Запись каждого APDU-запроса (TX) и ответа (RX, SW1/SW2) с расшифровкой статусных байтов карты. Лог сохраняется в файл `taho_debug.log` и в папку `logs/`, а также выводится в реальном времени в консоль интерфейса.
* 📁 **Быстрый доступ:** Кнопки прямого перехода к папке с дампами и открытия лог-файла в текстовом редакторе.

## Запуск из исходного кода

### Требования
* Python 3.7+ (рекомендуется Python 3.10+)
* Библиотека `pyscard`

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск GUI приложения
```bash
python main.py
```

### Запуск в консольном режиме (CLI)
```bash
# Просмотр доступных считывателей
python main.py --list-readers

# Дамп карты через первый подключенный считыватель (индекс 0)
python main.py --cli --reader 0

# Дамп карты мастерской с PIN-кодом
python main.py --cli --reader 0 --pin 1234
```

## Сборка в автономный `.exe` файл на Windows

Для сборки одного независимого `.exe` файла используется PyInstaller:
```bash
python build_exe.py
```
Собранный файл будет находиться в директории `dist/TahoDumper.exe`.
